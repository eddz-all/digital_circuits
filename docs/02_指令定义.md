# 指令定义

## 采用的 ARM 标准

本工程的可见 32-bit 指令字采用：

```text
Armv7-A/R AArch32 A32 instruction set encoding
也就是传统 ARM state 的 32-bit 定长 A32 编码
```

当前实现不是完整 ARM 处理器，而是 **bit-accurate A32 子集**：

```text
ROM 中实际使用的 MOV/ADD/SUB/AND/ORR/LDR/STR/B/BL/MOV pc,lr
以及 PKHBT/SADD16/SSUB16/SSAX/SMUAD/SMUSD/ASR
均按 A32 标准机器码编码。

decoder 只实现这些已用指令形式；其他合法 ARM 指令不保证支持。
```

所有 ROM 指令当前都使用 ARM 条件码：

```text
cond[31:28] = 1110 = AL = always
```

## 公共约定

```text
指令宽度：32 bit
寄存器：r0..r15
r14 = lr
r15 = pc
worker 内部 PC 使用 32-bit 字节地址；当前 ROM 深度为 64 条，所以取指索引用 PC[7:2]
```

worker 内部真正的 PC 信号是：

```text
pc_fetch_reg
```

分支立即数按 A32 规则理解为 word offset：

```text
target_addr = current_addr + 8 + (sign_extend(imm24) << 2)
```

ROM-local 预译码为了检查当前 64 条 ROM 窗口，会先用指令索引计算：

```text
target_index = pc_index + 2 + sign_extend(imm24)
```

然后输出给执行级的 `imm` 是 `target_index * 4`，也就是 32-bit 字节地址。

## 基础数据处理指令

### MOV immediate

本工程支持 `MOV rd, #imm8`，即 A32 `MOV (immediate)` 中 `rotate_imm=0` 的形式。

| 字段 | 位段 | 固定值/含义 |
| --- | --- | --- |
| `cond` | `[31:28]` | `1110` |
| class/opcode | `[27:20]` | `00111010` |
| `Rn` | `[19:16]` | `0000` |
| `Rd` | `[15:12]` | 目的寄存器 |
| `rotate_imm` | `[11:8]` | `0000` |
| `imm8` | `[7:0]` | 立即数 |

例子：

```text
MOV r0, #0   = 0xE3A00000
MOV r1, #91  = 0xE3A0105B
```

### Register data-processing

本工程支持未移位 register operand2 形式：

```asm
ADD rd, rn, rm
SUB rd, rn, rm
AND rd, rn, rm
ORR rd, rn, rm
MOV rd, rm
MOV pc, lr
```

| 字段 | 位段 | 固定值/含义 |
| --- | --- | --- |
| `cond` | `[31:28]` | `1110` |
| `I` | `[25]` | `0`，register operand2 |
| `opcode` | `[24:21]` | 指令 opcode |
| `S` | `[20]` | `0` |
| `Rn` | `[19:16]` | 源寄存器 1；`MOV` 中为 `0000` |
| `Rd` | `[15:12]` | 目的寄存器 |
| shift | `[11:4]` | `00000000`，未移位 |
| `Rm` | `[3:0]` | 源寄存器 2 |

| 指令 | opcode `[24:21]` | 例子 |
| --- | --- | --- |
| `AND` | `0000` | `AND r5,r3,r1 = 0xE0035001` |
| `SUB` | `0010` | `SUB r4,r3,r2 = 0xE0434002` |
| `ADD` | `0100` | `ADD r3,r1,r2 = 0xE0813002` |
| `ORR` | `1100` | `ORR r6,r5,r2 = 0xE1856002` |
| `MOV` | `1101` | `MOV pc,lr = 0xE1A0F00E` |

### ASR immediate

`ASR rd, rn, #imm` 在 A32 中是 `MOV rd, rn, ASR #imm` 的别名。本工程按这个标准编码识别。

| 字段 | 位段 | 固定值/含义 |
| --- | --- | --- |
| `[31:20]` | `E1A` | AL 条件、MOV register opcode、`S=0` |
| `Rn` | `[19:16]` | `0000`，MOV opcode 固定不用 |
| `Rd` | `[15:12]` | 目的寄存器 |
| `imm5` | `[11:7]` | 算术右移位数 |
| shift type | `[6:5]` | `10` = ASR |
| `[4]` | `0` | immediate shift |
| `Rm` | `[3:0]` | 源寄存器 |

例子：

```text
ASR r7, r7, #7 = MOV r7, r7, ASR #7 = 0xE1A073C7
```

## Load/Store 指令

本工程支持 A32 immediate offset、pre-index、no writeback、word access，并且当前只实现 `Rn=r0`：

```asm
LDR rd, [r0, #imm12]
STR rd, [r0, #imm12]
```

| 字段 | 位段 | `LDR` | `STR` |
| --- | --- | --- | --- |
| `cond` | `[31:28]` | `1110` | `1110` |
| `[27:20]` | addressing/L bit | `01011001` | `01011000` |
| `Rn` | `[19:16]` | `0000` | `0000` |
| `Rt/Rd` | `[15:12]` | load 目标寄存器 | store 数据寄存器 |
| `imm12` | `[11:0]` | byte offset | byte offset |

例子：

```text
LDR r5, [r0, #0x40]   = 0xE5905040
STR r10, [r0, #0x80]  = 0xE580A080
```

内部数据内存地址映射：

```text
word_addr = imm12 / 4
```

| word 地址范围 | 译码结果 | 内部 idx |
| --- | --- | --- |
| `16..23` | `dmem_bank0` | `word_addr - 16` |
| `32..39` | `dmem_bank1` | `word_addr - 32` |
| 其他 | illegal | 无 |

## Branch 指令

| 指令 | 高 8 bit | 含义 |
| --- | --- | --- |
| `B target` | `0xEA` | A32 branch，`L=0` |
| `BL target` | `0xEB` | A32 branch with link，`L=1` |

例子：

```text
B pc17   = 0xEA000000  ; pc15 -> pc17
BL pc21  = 0xEB000002  ; pc17 -> pc21, lr = byte address of pc18
B .      = 0xEAFFFFFE  ; standard A32 self-loop sentinel
```

## ARM DSP / Parallel 指令

### PKHBT

本工程支持 A32 `PKHBT rd, rn, rm, LSL #imm5`。

| 字段 | 位段 | 固定值/含义 |
| --- | --- | --- |
| `cond` | `[31:28]` | `1110` |
| `[27:20]` | `01101000` | PKHBT/PKHTB 类编码中的 PKHBT 形式 |
| `Rn` | `[19:16]` | 低半字来源 |
| `Rd` | `[15:12]` | 目的寄存器 |
| `imm5` | `[11:7]` | LSL 位数 |
| shift type | `[6:5]` | `00` = LSL |
| `[4]` | `1` | 固定识别位 |
| `Rm` | `[3:0]` | 高半字来源 |

例子：

```text
PKHBT r3, r1, r1, LSL #16 = 0xE6813811
PKHBT r9, r7, r8, LSL #9  = 0xE6879498
```

### SADD16 / SSUB16 / SSAX

| 字段 | 位段 | 固定值/含义 |
| --- | --- | --- |
| `cond` | `[31:28]` | `1110` |
| `[27:20]` | `01100001` | parallel signed add/subtract family |
| `Rn` | `[19:16]` | 源寄存器 1 |
| `Rd` | `[15:12]` | 目的寄存器 |
| `[11:8]` | `1111` | 固定识别位 |
| sub-op | `[7:4]` | 子操作 |
| `Rm` | `[3:0]` | 源寄存器 2 |

| 指令 | sub-op `[7:4]` | 例子 |
| --- | --- | --- |
| `SADD16` | `0001` | `SADD16 r10,r5,r6 = 0xE615AF16` |
| `SSUB16` | `0111` | `SSUB16 r11,r5,r6 = 0xE615BF76` |
| `SSAX` | `0101` | `SSAX r9,r0,r6 = 0xE6109F56` |

### SMUAD / SMUSD

| 字段 | 位段 | 固定值/含义 |
| --- | --- | --- |
| `cond` | `[31:28]` | `1110` |
| `[27:20]` | `01110000` | signed dual multiply family |
| `Rd` | `[19:16]` | 目的寄存器 |
| `[15:12]` | `1111` | 固定识别位 |
| `Rm` | `[11:8]` | 源寄存器 2 |
| sub-op | `[7:4]` | 子操作 |
| `Rn` | `[3:0]` | 源寄存器 1 |

注意：这类标准 A32 编码的寄存器字段顺序不是 `Rn,Rd,Rm` 连续排列，decoder 已按标准字段重新映射到内部 `rd/rn/rm`。

| 指令 | sub-op `[7:4]` | 例子 |
| --- | --- | --- |
| `SMUAD` | `0001` | `SMUAD r7,r6,r3 = 0xE707F316` |
| `SMUSD` | `0101` | `SMUSD r8,r6,r4 = 0xE708F456` |

## NOP 和完成哨兵

| 指令 | 标准编码 | 工程语义 |
| --- | --- | --- |
| `NOP` | `0xE1A00000` | A32 `MOV r0,r0` |
| `B .` | `0xEAFFFFFE` | 标准 A32 自跳转；worker 按 `WOP_B` 执行，顶层/测试环境把看到该指令作为完成哨兵 |
