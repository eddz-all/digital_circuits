# 元件概述

## 整体结构

```text
四个 worker
每个 worker 都是一套小 MCU 执行单元
```

每个 worker 主要包括：

```text
PC
指令 ROM
译码器
控制器
寄存器组
ALU
SIMD/DSP 运算逻辑
数据内存访问接口
写回通路
```

## PC

作用：

```text
保存当前取指位置的 32-bit 字节地址
```

RTL 中的主 PC 信号：

```text
pc_fetch_reg
```

它保存的是字节地址。当前 ROM 深度为 64 条，所以实现窗口是：

```text
0x00000000..0x000000FC
```

取指时：

```text
pc_index = pc_fetch_reg[7:2]
```

debug 输出时：

```text
pc_debug = pc_fetch_reg
```

也就是说，PC 本身就是 32-bit 字节地址；只是当前小 ROM 用 `PC[7:2]` 选中 64 条指令。

普通指令：

```text
pc = pc + 4
```

双发射：

```text
pc = pc + 8
```

分支跳转：

```text
pc = target byte address
```

## 指令 ROM

作用：

```text
保存程序指令
```

当前上板版本的指令 ROM 同时输出两类东西：

```text
原始 32-bit 指令字
预译码后的 op/rd/rn/rm/imm/idx/illegal
```

也就是说，ROM 里仍然保存真实机器码，但为了时序，译码结果也提前做成常量表。

FFT 模式下：

```text
worker0 读自己的 FFT 指令
worker1 读自己的 FFT 指令
worker2 读自己的 FFT 指令
worker3 读自己的 FFT 指令
```

基础测试模式下：

```text
只启动一个 worker
执行基础测试指令
```

## 译码器

作用：

```text
把 32-bit 指令翻译成 worker 内部能用的控制信息
```

实现上有两种入口：

```text
mcu4_worker_decoder.vhd       独立译码器
mcu4_worker_instr_rom.vhd     ROM 内部预译码
```

当前上板版本主要靠 ROM 内部预译码结果给 worker 使用。

例如：

```asm
ADD r3, r1, r2
```

译码后得到：

```text
op = ADD
rd = r3
rn = r1
rm = r2
```

访存指令还会译码出：

```text
bank
idx
```

## 控制器

控制器就是 worker 的状态机。

状态名包括：

```text
S_FETCH
S_DECODE
S_RUN
S_DSP_MUL
S_DSP_ACC
S_DSP_WB
```

这些状态只是说明当前 worker 在做：

```text
取指
译码
执行
多周期 DSP 运算
```

这不是 FFT 专用硬件。

## 寄存器组

每个 worker 有自己的寄存器组：

```text
r0..r15
```

特殊寄存器：

| 寄存器 | 用途 |
| --- | --- |
| `r14` | `lr`，保存返回地址 |
| `r15` | `pc`，用于返回跳转 |

## ALU

作用：

```text
执行普通整数和逻辑运算
```

支持：

```text
MOV
ADD
SUB
AND
ORR
ASR
B
BL
```

当前没有单独画成一个 `alu.vhd`，但硬件功能存在于 worker 执行级。

## SIMD 运算逻辑

作用：

```text
一次处理一个 32-bit word 里的两个 16-bit 数据
```

支持：

```text
SADD16
SSUB16
SSAX
PKHBT
```

FFT 中一个 word 表示一个复数：

```text
低 16 位 = real
高 16 位 = imag
```

## DSP 乘加逻辑

作用：

```text
为 SMUAD/SMUSD 完成两个 16-bit 乘法，再做加法或减法
```

支持：

```text
SMUAD
SMUSD
```

v3 中乘法器是手写两级结构：

```text
mul_s16_stage1：部分积生成和 CSA 压缩
mul_s16_stage2：继续压缩并得到 32-bit signed 乘积
```

这部分是多周期执行，不使用 FPGA DSP48。

## 数据内存

当前数据内存分成两个 bank：

| bank | 大小 | 作用 |
| --- | --- | --- |
| `bank0` | 8 个 32-bit word | 输入和中间结果 |
| `bank1` | 8 个 32-bit word | 中间结果和最终输出 |

内部访问方式：

```text
bank + idx
```

## 访存接口

`LDR`：

```text
从 bank[idx] 读数据
写回寄存器
```

`STR`：

```text
从寄存器取数据
写入 bank[idx]
```

## 写回通路

作用：

```text
把 ALU / SIMD / DSP / LDR 的结果写回寄存器组
```

双发射时可以一拍写回两个结果。

## 多核连接

四个 worker 同时跑。

每个 worker 独立拥有：

```text
PC
寄存器组
指令流
控制器
执行逻辑
```

数据 bank 的内容保持一致。

worker 写数据时，会同步更新各个 worker 可读的 bank 副本。

## 板级辅助

| 元件 | 作用 |
| --- | --- |
| `test_ROM` | 提供输入样本 |
| `verify_RAM` | 保存输出结果 |
| 计数器 | 统计 worker 执行周期 |
| ILA | 板上观察调试信号 |
